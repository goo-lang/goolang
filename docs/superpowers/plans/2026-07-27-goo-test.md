# `goo test` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `goo test [dir]` discovers `func TestXxx(t *testing.T)` in a package's `_test` files, runs each, prints Go's output format, and exits 1 on any failure.

**Architecture:** A new CLI mode reuses two existing paths — the directory entry-package machinery (PR #226) collects the files, and `goo run`'s temp-binary + exec path runs the result. `testing` is a bespoke shim following the `sync.Mutex` model (seeded exports, not the `SHIM_TABLE`). A synthesized `_testmain.goo` is parsed as one more file of the package and passes each test **as a function value**, so the runtime owns the call frame and can `longjmp` out of `t.Fatal`. The C runtime owns all output and the exit status.

**Tech Stack:** C23, bison/flex frontend, LLVM 22 codegen, existing golden + reject + cli_test harnesses.

**Spec:** `docs/superpowers/specs/2026-07-27-goo-test-design.md`

## Resolved before planning (do not re-litigate)

- **`testing` must NOT use `SHIM_TABLE`** (`src/types/shim_signatures.c`). `ShimParamKind` is a closed enum — `SHIM_PARAM_STRING`, `_INT64`, `_FLOAT64`, `_ERROR`, `_STRING_SLICE` — with no func kind, so `Run(string, func(*T))` is inexpressible there. Use the seeded-exports path that `sync` and `time` use: `time_export_func` takes `Type**`, so a func-typed parameter is an ordinary `type_function(...)`.
- An entry package whose clause is not `main` compiles and runs (measured). The test binary needs no package rename.
- `fmt.Sprintf` with a non-literal format is rejected, and `fmt.Println(args...)` does not spread. Both measured. This is why `testing` is not Goo source in `goostd/`.

void seed_testing_package_exports(TypeChecker* checker, Package* pkg) {
    if (scope_lookup_variable(pkg->exports, "T")) return;

    Type* void_t   = type_checker_get_builtin(checker, TYPE_VOID);
    Type* string_t = type_checker_get_builtin(checker, TYPE_STRING);

    // Opaque one-pointer struct, exactly like sync.Mutex: the runtime owns
    // the real state; Goo only ever passes *T around.
    Type* t_ty = sync_make_opaque_struct(checker, pkg, "T");
    if (!t_ty) return;

    // cannot live in SHIM_TABLE — ShimParamKind has no func kind — and why

    Type* tp_ty  = type_pointer(t_ty);

    Type* fn_ty  = type_function(fn_params, 1, void_t);
    Type* run_params[] = { string_t, fn_ty };

- [ ] **Step 6: Write the runtime**

```c
#include "runtime.h"
#include <stdio.h>
#include <string.h>
#include <time.h>

// One test's state. The Goo-visible testing.T is an opaque one-pointer
// struct whose field holds a GooTest*.
typedef struct {
    const char* name;
    int failed;
} GooTest;

static int  g_total;
static int  g_failed;
static double g_elapsed;

static double now_sec(void) {
    struct timespec ts;
    clock_gettime(CLOCK_MONOTONIC, &ts);
    return (double)ts.tv_sec + (double)ts.tv_nsec / 1e9;
}

void goo_testing_fail(void* handle) {
    GooTest* t = (GooTest*)handle;
    if (t) t->failed = 1;
}

void goo_testing_log_str(void* handle, goo_string_t msg) {
    (void)handle;
    printf("    %s\n", msg.data ? msg.data : "");
}

void goo_testing_run(goo_string_t name, void (*fn)(void*)) {
    GooTest t;
    t.name = name.data ? name.data : "";
    t.failed = 0;

    printf("=== RUN   %s\n", t.name);
    double start = now_sec();
    if (fn) fn(&t);
    double dur = now_sec() - start;

    g_total++;
    g_elapsed += dur;
    if (t.failed) {
        g_failed++;
        printf("--- FAIL: %s (%.2fs)\n", t.name, dur);
    } else {
        printf("--- PASS: %s (%.2fs)\n", t.name, dur);
    }
}

void goo_testing_summary(void) {
    if (g_failed > 0) {
        printf("FAIL\n");
        goo_exit(1);
    }
    printf("ok  %.3fs\n", g_elapsed);
    goo_exit(0);
}
```

- [ ] **Step 3: Add the setjmp frame to the runtime**

In `src/runtime/testing.c`, add `#include <setjmp.h>`, extend the state, and wrap the call:

```c
typedef struct {
    const char* name;
    int         failed;
    jmp_buf     abort_to;
    int         abort_valid;
} GooTest;

void goo_testing_failnow(void* handle) {
    GooTest* t = (GooTest*)handle;
    if (!t) return;
    t->failed = 1;
    if (t->abort_valid) longjmp(t->abort_to, 1);
}
```

```c

documented limitation plus a reject or a note — do NOT silently ship a leak. Record whichever
outcome in the spec's Risks section.

// Go's rule exactly: the name begins with "Test" and the character after
// "Test" is not a lowercase letter. So TestAdd and Test_add are tests, bare
// Test is a test, and Testify is an ordinary function left alone.
//
// The name rule is what keeps the signature error honest: without the
// lowercase exclusion an ordinary helper called Testable would be pulled in
// and then rejected for the wrong reason.
static int is_test_name(const char* n) {
    if (!n || strncmp(n, "Test", 4) != 0) return 0;
    char c = n[4];
    if (c == '\0') return 1;
    return !(c >= 'a' && c <= 'z');
}

static int has_test_signature(FuncDeclNode* f) {
    if (f->return_type) return 0;
    if (f->receiver) return 0;
    size_t n = 0;
    ASTNode* p = f->params;
    for (; p; p = p->next) if (p->type == AST_VAR_DECL) n++;
    if (n != 1) return 0;
    // Exactly one param, and its declared type must be *testing.T.
    VarDeclNode* pd = (VarDeclNode*)f->params;
    return pd->type && pd->type->type == AST_POINTER_TYPE;   /* refined below */
}
```

Refine `has_test_signature` to confirm the pointee is the selector `testing.T` rather than any
pointer — inspect the `PointerTypeNode`'s `element_type` for an `AST_SELECTOR_EXPR` whose base
identifier is the import's local name and whose selector is `T`. Accepting any pointer type would
let `func TestX(p *int)` through and fail later with a confusing codegen error.

`test_discovery_collect` walks every program's `decls`, and for each `AST_FUNC_DECL` whose name
passes `is_test_name`: if `has_test_signature` fails, emit
`"%s must have signature func(t *testing.T)"` positioned at the decl and return 0; otherwise append
the name.

char* test_discovery_build_main(const char* package_name, const TestList* tests) {
    // package clause must match the package under test — the entry package's
    // clause need not be "main" (verified), so no rename is involved.
    size_t cap = 128 + strlen(package_name);
    for (size_t i = 0; i < tests->count; i++) cap += strlen(tests->names[i]) * 2 + 32;
    char* buf = malloc(cap);
    if (!buf) return NULL;
    int n = snprintf(buf, cap, "package %s\n\nimport \"testing\"\n\nfunc main() {\n",
                     package_name);
    for (size_t i = 0; i < tests->count; i++) {
        n += snprintf(buf + n, cap - (size_t)n, "\ttesting.Run(\"%s\", %s)\n",
                      tests->names[i], tests->names[i]);
    }
    snprintf(buf + n, cap - (size_t)n, "\ttesting.Summary()\n}\n");
    return buf;
}

table shape was verified to work, so this is a simplicity choice, not a capability one.

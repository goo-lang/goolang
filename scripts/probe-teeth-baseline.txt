# A probe with no negative control has never been shown capable of going red.
# It can pass forever while testing nothing, and that is not hypothetical: on
# 2026-08-20 repro_build_probe.sh's own self-test could not run on CI at all,
# and doc_claims_probe.sh's shim assertion stayed green under the exact
# mutation it was written to catch. Both were found only by running the
# negative case.
#
# probe-teeth-probe FAILS when a name appears here that is not a real probe,
# when a listed probe has since gained teeth (remove it from this list in the
# same commit), or when a probe exists that is neither toothed nor listed.
# That last rule is the point: a NEW probe cannot be added without teeth.
#
# A "teeth mechanism" is --self-test, SELFTEST, or MUTATE.
#
# Removing a line here means adding a negative control to that probe. That is
# the intended direction of travel; this list must never grow.

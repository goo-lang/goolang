# Security policy

## Supported versions

Goo has no release yet. Only the `main` branch receives security fixes.

## How to report a vulnerability

Do not open a public issue for a security defect.

Use GitHub private vulnerability reporting:

1. Open the Security tab of this repository.
2. Select "Report a vulnerability".
3. Fill in the form and submit it.

## What to include

- A minimal Goo program or a compiler command that shows the defect.
- The commit SHA of the compiler that you tested.
- The platform, for example the operating system and the CPU architecture.

## What to expect

- The maintainers acknowledge the report.
- The maintainers fix a confirmed defect on `main` through a pull request.
- The maintainers publish a GitHub security advisory for a confirmed defect.
